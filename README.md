# Level Up Earth (formerly PedhPoints)

**DO GOOD. GET REWARDED.**

Level Up Earth is a gamified, impact-driven application designed to motivate individuals to take actionable steps towards saving the planet. Instead of just talking about climate change, Level Up Earth rewards you for verifiable eco-actions like planting trees, saving water, reducing energy consumption, and more.

## Features

- **Brutalist UI**: Bold, striking design that reflects the urgency of climate action.
- **Global Impact Feed**: See live updates of what other Eco-Warriors are doing around the world.
- **Leaderboard**: Gamified ranking system to compete for the highest ecological impact.
- **Action Logging**: Upload proof of your actions (e.g., planting a tree) to earn points.
- **Admin Dashboard**: Specialized command center for verifying actions and managing the community.

## Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS
- **Authentication & Database**: Supabase
- **Icons**: Lucide React

## Getting Started

1. Clone the repository and install dependencies:
   ```bash
   npm install
   ```

2. Set up your `.env.local` file with Supabase credentials:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) to see the application.

## Core Philosophy

We believe in **Action First**. Thoughts and prayers don't lower carbon emissions. Upload photo proof of your eco-actions, get verified by the community or admins, and watch your rank climb on the global leaderboard. 

Designed for real-world impact.
